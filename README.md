# Лабораторная работа №4

**Решение задачи Дирихле для уравнения Пуассона**  
Метод Зейделя и метод верхней релаксации, вариант 6.

Проект повторяет архитектуру примера `boundary-value-problems-for-odes`: C++ backend считает задачи и пишет `result.json`/CSV, Tkinter UI показывает четыре вкладки, справки, таблицы и графики.

## Вариант 6

```text
a = 0, b = 1, c = 0, d = 2
Δu(x,y) = -f(x,y),  f(x,y)=|x-y|

u(0,y) = mu1(y) = sin^2(pi*y)
u(1,y) = mu2(y) = |exp(sin(pi*y))-1|
u(x,0) = mu3(x) = x(1-x)
u(x,2) = mu4(x) = x(1-x)exp(x)
```

Для тестовой задачи точное решение:

```text
u*(x,y)=exp(sin^2(pi*x*y))
```

## Распределение задач

| № | UI вкладка | C++ файл | Статус |
|---|---|---|---|
| 1 | Тестовая задача, метод Зейделя | `src/tasks/test_seidel.cpp` | заготовка |
| 2 | Тестовая задача, МВР | `src/tasks/test_sor.cpp` | заготовка |
| 3 | Основная задача, метод Зейделя | `src/tasks/main_seidel.cpp` | реализовано |
| 4 | Основная задача, МВР | `src/tasks/main_sor.cpp` | заготовка |

Твоя часть реализована в `src/tasks/main_seidel.cpp`: используется пятиточечная схема второго порядка, метод Зейделя, контроль точности через сравнение решений на сетках `(n,m)` и `(2n,2m)`.

Запуск интерфейса:


## Входные параметры

Файлы примеров лежат в `input_examples/`.

```json
{
  "n": 20,
  "m": 40,
  "tolerance": 5e-7,
  "methodTolerance": 1e-8,
  "maxIterations": 100000,
  "maxN": 80,
  "maxM": 160,
  "tableStrideX": 2,
  "tableStrideY": 4,
  "omega": 1.7
}
```

`omega` уже есть в контракте для участника с МВР. В реализованной вкладке Зейделя фактически используется `omega = 1`.
